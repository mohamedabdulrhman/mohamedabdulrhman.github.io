# Mohamed Abdulrahman — Professional Portfolio
This package contains the updated portfolio and redesigned CV.

## Open locally
1. Extract the ZIP completely.
2. Open `index.html` from the extracted folder (not from inside the ZIP).
3. Keep `style.css`, `script.js`, and `Mohamed_Abdulrahman_CV.pdf` beside `index.html`.
